# BikeHub

Велосообщество с механикой Drive2: у владельца есть гараж, у велосипеда — карточка и бортжурнал, записи попадают в общую ленту и ленту подписок.

## Быстрый старт

Нужны .NET 10 и Node.js 22.12+.

```bash
# Терминал 1. В Development PostgreSQL не нужен.
dotnet run --project src/BikeHub.Api --launch-profile http

# Терминал 2
cd Web
npm ci
npm run dev
```

Интерфейс: http://localhost:5173. Swagger: http://localhost:5179/swagger.
Vite проксирует `/api` на `127.0.0.1:5179`, поэтому CORS для разработки не требуется.

## Первая версия

- Лента «Для вас», «Подписки», «Популярное», поиск и фильтры по типу велосипеда.
- Каталог велосипедов, личный гараж, карточка велосипеда и бортжурнал.
- Профили владельцев и подписки.
- Создание велосипеда и публикация записи в его бортжурнале.
- Лайки, закладки, комментарии и вступление в сообщества.
- Адаптивный интерфейс, мобильное меню, состояния загрузки, ошибок и пустых списков.

В этой версии выбран один демонстрационный пользователь — Александр Волков. Авторизация и загрузка собственных фотографий ещё не реализованы; обложка новой записи берётся из карточки велосипеда. Все операции работают через API. Моковые сервисы используют общее потокобезопасное хранилище в памяти одного процесса: изменения сбрасываются при перезапуске, экземпляры приложения не синхронизированы.

## Структура

- `Web` — React, TypeScript, Vite; страницы и общие компоненты.
- `src/BikeHub.Application/Community` — DTO, валидация входных данных и интерфейсы пяти сервисов.
- `src/BikeHub.Api/Controllers` — HTTP-контроллеры.
- `src/BikeHub.Api/Services` — реализации моков и начальные данные.

Сервисы зарегистрированы через DI: при подключении реального хранилища можно заменить реализации интерфейсов без изменения HTTP-контракта. Существующие DAL и миграции сохранены. В `Development` bootstrap и миграции отключены; `--migrate-only` продолжает запускать миграции явно.

## Сборка и проверка

```bash
dotnet build BikeHub.sln
cd Web
npm run build
```

При запущенном API из корня репозитория:

```bash
python3 scripts/smoke-api.py
```

Smoke-тест проверяет HTTP-контракты и сквозные сценарии. Добавляет тестовый велосипед, запись и комментарий в память; перезапустите API для восстановления исходных данных.

## Docker

```bash
docker compose up --build
```

Сайт и API доступны на http://localhost:8080. Dockerfile собирает фронт отдельным этапом и копирует `dist` в `wwwroot` API; nginx сохраняет существующий маршрут. Для запуска образа без БД задайте `Database__BootstrapEnabled=false` и `Database__MigrationsEnabled=false`.

Для локальной раздачи production-сборки можно скопировать содержимое `Web/dist` в `src/BikeHub.Api/wwwroot` перед запуском API. Генерируемые файлы не коммитятся.
