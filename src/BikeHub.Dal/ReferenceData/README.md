# Города России

`Cities.v1.json` — переработанный снимок [HFLabs/city](https://github.com/hflabs/city/tree/ae661bffe572880472249097c9b29c42b09650ea), commit `ae661bffe572880472249097c9b29c42b09650ea`, получен 17 ноября 2026. Автор исходного набора — HFLabs; данные получены авторами из DaData и Википедии. Исходный набор и эти производные JSON распространяются по [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). Эта лицензия относится к данным справочника, а не к остальному коду проекта.

Из исходного CSV оставлены 1117 городов: ФИАС UUID, название, регион и население для порядка подсказок. Для городов внутри других городов выбрано название конечного населённого пункта (`settlement`); федеральные города и некоторые городские округа восстановлены из полей региона/района. Тип региона раскрыт, одноимённые города получили регион в `label`. Добавлены общеупотребительные алиасы, включая СПб/Питер/Петербург и МСК. Размер населения используется только для ранжирования, не как актуальная статистика.

Это фиксированный стартовый справочник, а не полный актуальный ГАР: сёла, посёлки, зарубежные и появившиеся после снимка города могут отсутствовать. Расширение выполняется новой проверенной версией данных. Справочник работает без сети, ключей и стороннего autocomplete API; введённые пользователем значения не отправляются стороннему сервису.

`CanonicalCityAliases.v1.json` — неизменяемый снимок однозначных ключей для миграции `20261117120000_CanonicalCities`. Не менять и не удалять этот ресурс при обновлении каталога. Миграция исправляет известные варианты во всех трёх колонках `city`, сохраняет неоднозначные/неизвестные значения и может выполняться повторно. Схема БД и исходные ФИАС-коды не меняются: в существующих колонках сохраняется канонический `label`.
