# Справочник городов

Профиль, создание/редактирование покатушек и маршрутов, оба фильтра города используют один `CityInput`. Подсказки появляются по мере ввода, работают мышью, касанием и стрелками/Enter; Escape закрывает список. Ошибка загрузки допускает повтор без потери ввода. Запросы выполняются только к API BikeHub и учитывают базовый путь `/bikehub/`.

`GET /api/cities?q=...` доступен гостям без БД, возвращает до 12 вариантов `{id, name, region, label}`. `id` — ФИАС UUID из фиксированного источника. Поиск учитывает регистр, ё/е, пробелы/дефисы и известные алиасы. Небольшие опечатки дают подсказки, но не автоматическую замену. Для совпадающих названий отображается регион; для сохранения требуется полное однозначное `label`.

API нормализует города при записи профиля, покатушки и маршрута, а также при поиске по городу. Например, `Питер`, `СПб`, `санкт петербург` дают `Санкт-Петербург`. Произвольное новое название отвергается с 400 и предложением выбрать из справочника. Город профиля можно очистить. Неизвестное старое значение можно сохранить без изменения при редактировании других полей.

В существующих колонках `city` хранится канонический `label`, для одноимённых городов — с регионом. Новые внешние ключи не вводятся. Миграция `20261117120000_CanonicalCities` приводит однозначные старые варианты к справочнику, не угадывает регион для неоднозначных названий и не затирает неизвестные значения. Повторный запуск безопасен, откат — из резервной копии.

Стартовый набор: 1117 городов, источник/версия/лицензия и правила обновления — в [описании данных](../src/BikeHub.Dal/ReferenceData/README.md). Не является полным актуальным ГАР; расширение набора возможно без изменения контракта полей. Доступ к интернету, платные API и ключи во время работы не нужны.
