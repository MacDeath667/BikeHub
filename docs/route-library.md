# Библиотека маршрутов

Раздел «Маршруты» хранит самостоятельные публикации с GPX или ручной картой, городом, описанием и покрытием: асфальт, гравий, тропы или смешанное. Есть фильтры по городу, дистанции и покрытию, свои публикации и сохранённые. Из карты поста, обсуждения или покатушки можно открыть новую публикацию с копией маршрута; исходный материал проверяется обычным API доступа. Публикация копии требует отдельного нажатия кнопки.

Дистанция вычисляется сервером по точкам каждого сегмента. Разрывы трека и отдельные метки не соединяются; это длина линии без построения дороги и без учёта высоты. Максимум — 30 000 точек и 100 000 км. Списки не возвращают весь трек, карта карточки получает ограниченное превью по мере появления в области просмотра.

Сохранение для себя содержит необязательную подборку и личную заметку. Они не видны автору маршрута, другим пользователям и гостям. Подборок до 50, имена уникальны внутри аккаунта без учёта регистра. При удалении подборки сохранённые маршруты и заметки остаются. Удаление из сохранённых удаляет соответствующую заметку. Подборки пока приватные, публичных ссылок на них нет.

Отзывы после поездки: оценка 1–5, текст и дата состоявшейся поездки. Повторное сохранение обновляет один отзыв пользователя. Дата проверяется по указанному часовому поясу устройства; API без пояса использует UTC. Автор маршрута получает одно уведомление, правки отзыва не создают повторную рассылку. Скрытые, удалённые отзывы и заблокированные авторы исключены из списка и среднего рейтинга.

## API

- `GET /api/route-library?city=&surface=&minimum=&maximum=&mine=false&saved=false&collectionId=&page=1&pageSize=20` — до 50 результатов. Личные фильтры требуют входа; чужая подборка возвращает 404.
- `GET /api/route-library/{id}` — подробности, полный маршрут и заметка только текущего пользователя; `GET .../{id}/preview` — упрощённая карта.
- `POST /api/route-library`, `PUT /api/route-library/{id}` — публикация и изменение. Изменение требует актуальной `revision`, иначе 409.
- `PUT .../{id}/bookmark` с `note` и `collectionId`, `DELETE` этого адреса — сохранение/удаление из сохранённых.
- `GET/POST /api/route-collections`, `PUT/DELETE /api/route-collections/{id}` — личные подборки.
- `GET .../{id}/reviews`, `PUT .../{id}/reviews/me`, `DELETE .../{id}/reviews/{reviewId}` — отзывы.

Модерация принимает жалобы на маршрут (`targetType: 11`) и отзыв (`12`), поддерживает скрытие и восстановление. Скрытый маршрут или заблокированный владелец закрывают подробности, превью, отзывы и связанные уведомления. При удалении профиля удаляются его маршруты, отзывы, сохранения и подборки. Новые таблицы входят в штатные дампы БД. Миграция `RouteLibrary` использует raw SQL и `IF NOT EXISTS`.

Пока нет автоматического построения пути по дорогам, высотного профиля, импорта активности из велокомпьютера и совместного редактирования подборок.
