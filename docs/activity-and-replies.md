# Общая лента и ответы

`GET /api/feed/timeline` возвращает страницы `FeedItemDto`: запись велосипеда (`kind: 1`, `post`) или запись/обсуждение сообщества (`kind: 2`, `groupEntry`). Внешний ID содержит префикс источника; для переходов используются ID вложенных материалов. Старый `/api/feed` остаётся доступен.

«Подписки» требуют входа: записи подписанных авторов и записи сообществ, в которых состоит пользователь. «Для вас» — общая публичная лента, «Популярное» — лайки записей и число ответов обсуждений. Это простая сортировка по активности. Порядок при равных датах и оценках фиксирован типом и ID. Страницы ограничены 50 элементами, тело маршрута в списки не попадает. Изменения данных между запросами могут сместить страницы; интерфейс объединяет пересекающиеся результаты по ID.

## Ответы

При создании комментария `/api/posts/{id}/comments` и ответа `/api/group-entries/{id}/replies` можно передать `replyToId`. Исходный комментарий должен относиться к тому же материалу и быть видимым. В группе требуется членство. Связь после публикации не меняется; ответ на ответ разрешён. Интерфейс показывает адресата и краткую цитату без увеличения отступов на каждом уровне.

`replyToId` хранится отдельно, цитата загружается из актуального исходного комментария. Удалённые, скрытые и заблокированные источники возвращают `replyTo: null`, их содержимое не раскрывается. При физическом удалении исходного комментария (включая удаление аккаунта) внешний ключ обнуляет ссылку; чужой ответ остаётся, если сам материал сохраняется.

Уведомление об адресном ответе получает автор исходного комментария; самому себе уведомления не создаются. Упоминания работают отдельно с исключением повторного уведомления прямого адресата. Ответ без адресата уведомляет автора материала.

Уведомления открывают `?comment={id}`. Отдельные GET `/api/posts/{postId}/comments/{commentId}` и `/api/group-entries/{entryId}/replies/{replyId}` позволяют показать ответ, не загружая все предыдущие страницы. Такие ссылки и цитаты также проверяют видимость исходного материала.

Миграция `CommentReplies` добавляет nullable-ссылки и индексы через повторяемый raw SQL. Откат выполняется восстановлением резервной копии, а не удалением столбцов.
