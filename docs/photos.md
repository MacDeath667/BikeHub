# Фотографии велосипедов и записей

В гараже нажмите «Добавить велосипед», выберите до 10 фотографий и заполните карточку. Можно выбрать несколько файлов сразу или перетащить их в форму. Первое фото используется как обложка; кнопка «Сделать обложкой» переносит выбранное фото на первое место. Любое фото можно убрать из подборки перед сохранением.

Для публикации откройте велосипед и нажмите «Новая запись» в бортжурнале либо используйте создание записи из ленты. Выберите свой велосипед, добавьте фотографии, заголовок и текст. Без собственных фото запись показывает карту, если добавлен маршрут; иначе используется обложка велосипеда. После публикации запись появляется в бортжурнале и ленте.

В карточке велосипеда и на странице записи фотографии переключаются миниатюрами. Нажатие на фото открывает просмотр крупным планом; доступны стрелки клавиатуры и Escape. Владелец может менять подборку через «Редактировать».

Поддерживаются JPEG, PNG и WebP, до 10 МБ на файл и 24 мегапикселей. Файлы загружаются последовательно, перекодируются в WebP до 1600 px, метаданные и геометки удаляются. Сохраняются прежние лимиты: 50 загрузок в сутки и 250 МБ на аккаунт.

## API

- `POST /api/media` — загрузка одного multipart-файла, ответ `{id,imageUrl,width,height}`. Требуются вход и CSRF.
- Создание/редактирование велосипеда и поста принимает упорядоченный `imageIds: Guid[]`, максимум 10 разных собственных загруженных фотографий. Первый ID — обложка; пустой массив убирает собственные фото. Чужие, отсутствующие и удалённые фотографии отклоняются.
- Ответы содержат `photos: [{id,imageUrl}, ...]`, а также `imageUrl` и `imageId` обложки. Прежний входной `imageId` поддерживается, если `imageIds` не указан.
- Фото опубликованной галереи доступно гостям. До публикации файл доступен владельцу. Удаление фото из подборки закрывает публичный доступ, если оно не используется другим видимым материалом или аватаром.

Миграция `ContentPhotoGalleries` добавляет PostgreSQL-массивы `image_ids` через `IF NOT EXISTS` и переносит прежние одиночные обложки. Повторное применение не перезаписывает существующие подборки. Удаление из подборки не удаляет физический файл: он может использоваться другим материалом; неиспользуемые файлы старше суток очищаются фоновым обработчиком.

## Кадрирование аватарок

При выборе фотографии для профиля или сообщества сначала открывается редактор: квадратная рамка и круглое превью рядом. Фотографию можно двигать мышью, пальцем или стрелками клавиатуры, а масштаб менять ползунком. Кадр всегда остаётся в границах исходного изображения. «Сбросить» возвращает центральную область; «Отмена» или Escape закрывает кадрирование без изменения прежней аватарки.

«Применить обрезку» создаёт в браузере квадратное изображение до 512 × 512 px и загружает только его. Исходный файл на сервер не отправляется. API по-прежнему проверяет и перекодирует изображение в WebP. Затем нужно сохранить сам профиль или сообщество, чтобы привязать новую аватарку. Если загрузка не удалась, выбранный кадр остаётся для повтора; сохранять форму до применения либо отмены кадрирования нельзя. Фотографии постов и велосипедов этим редактором не обрезаются.

Сборка: `npm --prefix Web run build`. Проверки геометрии и совпадения круглого превью с квадратной областью: `npm --prefix Web test`.
