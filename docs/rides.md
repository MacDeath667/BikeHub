# Покатушки

Раздел «Покатушки» в меню: ближайшие встречи с фильтром по городу, личное участие и прошедшие. Со страницы сообщества доступны его покатушки и создание встречи от сообщества. Создавать и записываться могут подтверждённые пользователи; для публикации от сообщества организатор должен состоять в нём. Другим подтверждённым пользователям вступление в группу для участия в открытой встрече не требуется.

Встреча содержит название, описание, город, время и часовой пояс, место встречи с необязательными координатами, дистанцию, средний темп, нагрузку и необязательный лимит мест. Маршрут задаётся GPX или вручную существующим редактором. Место встречи можно взять из первой точки маршрута. Организатор входит в число мест. «Возможно» мест не занимает. Списки участников ограничены страницами и показывают публичные профили без email.

Дата сохраняется в UTC вместе с IANA-часовым поясом встречи. Форма и карточка показывают время этого пояса. Переходы летнего времени, создающие отсутствующее или двусмысленное локальное время, явно отклоняются формой. Создание и перенос встречи разрешены на будущую дату в пределах двух лет. Отменённые встречи остаются доступны по ссылке и в «Моих покатушках»; запись после отмены или начала закрыта.

## API

- `GET /api/rides?city=&groupId=&mine=false&past=false&page=1&pageSize=20` — список, максимум 50. `mine` требует входа.
- `GET /api/rides/{id}` — подробности с маршрутом. В списке вместо большого маршрута возвращается только `hasRoute`.
- `GET /api/rides/{id}/participants` — участники, те же ограничения страниц.
- `POST /api/rides`, `PUT /api/rides/{id}` — создание и изменение. Для изменения обязательна актуальная `revision`; конфликт возвращает 409.
- `PUT /api/rides/{id}/attendance` с `attendance: 1` (еду) или `2` (возможно); `DELETE` этого адреса — выход.
- `POST /api/rides/{id}/cancel` с `revision` — отмена. Повтор отмены не создаёт второе событие.
- `DELETE /api/rides/{id}` — удаление организатором/модератором. Встречу с другими участниками сначала необходимо отменить.

Изменения и запись сериализуются блокировкой строки встречи, поэтому одновременная запись не превышает лимит. Повтор той же записи идемпотентен. Сохранение неизменных полей не увеличивает версию и не уведомляет участников. Каждое действительное изменение получает отдельное событие `ride_changes`; уведомления участникам формируются в той же транзакции одним `INSERT SELECT`. Это уведомления внутри BikeHub, без email-рассылки. Действует существующее исключение уведомлений самому себе и заблокированных аккаунтов.

Модерация поддерживает жалобу и скрытие покатушки (`targetType: 9`). `targetType: 10` используется только уведомлениями изменений, не принимает жалоб. Скрытая/удалённая группа, скрытая встреча или блокировка организатора исключают встречу и её уведомления из публичной выдачи. Удаление профиля удаляет его встречи и участие в чужих встречах; резервные копии PostgreSQL включают новые таблицы штатным дампом.

Пока нет листа ожидания, чата встречи, повторяющихся событий, календарной подписки и автоматических напоминаний перед стартом. Локальный запуск новых постоянных функций требует PostgreSQL из штатного Compose. Новая миграция `GroupRides` повторяемая, raw SQL с `IF NOT EXISTS`.
